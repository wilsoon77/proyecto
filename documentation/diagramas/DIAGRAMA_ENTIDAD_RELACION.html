Modelo de Base de Datos • Relacional / Prisma ORM • Formato Vertical

Diagrama de Modelo Entidad-Relación (MER / Relational Data Model)

Estructura relacional de PostgreSQL para la gestión multi-sucursal, producción por amasijos, control FEFO y reservas B2C.

Regla de Arquitectura de Datos: El modelo relacional implementa restricciones estrictas de integridad referencial (FK), índices compuestos para acelerar filtros por sucursal y fecha contable (branchId, closeDate), y partición de inventario en doble nivel: resumen balanceado (Inventory) y trazabilidad por lotes (InventoryLot) para soporte FEFO.
