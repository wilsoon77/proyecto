Checkout de Reserva y Comprobante con Código de Retiro

Estructura para el formulario de contacto, confirmación de sucursal y comprobante de reserva.

Seguridad Transaccional: Esta reserva cuenta con un TTL de retención de inventario de 60 minutos en la base de datos PostgreSQL de Panadería Svetlana.
Ficha Técnica de Wireframe (WF-02): Define la pantalla de confirmación y cierre de reserva B2C. Presenta desglose contable (Subtotal, IVA 15%, Total), datos del cliente y voucher digital con código QR y PIN alfanumérico para validación rápida en mostrador.
